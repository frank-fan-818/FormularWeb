# 原生 App 平铺界面原型 QA

- Date: 2026-10-27（Asia/Shanghai）
- 范围：`docs/design/native-app/` 独立评审原型；不包含现有 Web 路由或 Android APK。
- 后续已新增 Kotlin 原生工程，构建证据见 [Android 原生 QA](native-android-mvp.md)；本报告仍只代表浏览器原型检查。
- 设计依据：用户确认四入口结构，要求减少框线、卡片和嵌套容器。
- Build or dev URL: 直接用本机 Chrome 打开 `docs/design/native-app/index.html`；文件中明确标记示例数据。
- 命令：`node --check docs/design/native-app/prototype.mjs`；`node docs/design/native-app/verify.mjs`。
- 原型为纯静态 HTML/CSS/JS，无生产代码改动；没有需要执行的生产构建或独立业务单元测试。本次以语法检查、浏览器交互断言与截图检查验证实际改动。

## 检查范围

- 赛事首页、赛历、比赛概览、场次成绩、圈速对比、榜单、资料、个人设置及档案下钻。
- 320、360、375、412、768 和 1440 px 视口；移动截图为 375 × 812，桌面为 1440 × 900。
- 返回保留场次、榜单分类和资料查询词；主入口有各自的浏览状态。
- 成绩场次底部选择面板、车手对比选择、圈数滑动输入和可访问的逐圈数据视图。
- 深色主题和时区切换跨导航保持，时区更新会改变日程显示时间。
- 加载、尚未发布、错误重试与离线缓存的设计状态。所有状态均由示例驱动，不发起真实赛事请求。

## 结果

- 自动交互断言通过，检查的页面无横向溢出。
- 正文保留一层 16px 侧边留白，列表与图表没有额外卡片内边距。
- 截图人工检查：成绩行按名次、车手和成绩对齐，仅使用轻量分隔线，没有包裹每行的外框、圆角卡片或嵌套信息框；图表直接使用正文宽度。
- 无浏览器控制台错误/警告、页面异常和失败网络请求。
- 首次浏览器检查发现主导航隐藏状态可能被 CSS 覆盖，以及跨入口恢复会覆盖全局主题/状态；已在验证前修正并加入对应交互断言。
- Blocking: 当前原型评审无阻塞。

## 第二版视觉修订

- 用户反馈第一版过度简化、视觉欠佳，要求大部分参考现有网站设计。
- 参考现有 `ProductPage.css`、`Home.css`、赛事 editorial 样式，以及已有的 light-mobile 网站截图，复用字体、红色强调线、轻量网格、车手头像和车队色。
- 移除 ITALIA 大装饰字和夸张空白，缩小赛事标题并收紧列表间距；四入口和无嵌套卡片布局保持。
- 字体和头像由 `prepare-assets.mjs` 从仓库已有资源生成内联预览资源，无额外网络依赖。验证实际字体栈为 F1 UI Display；截图检查字体和头像加载。
- 已重新运行完整原型检查，覆盖相同六档视口、主要操作与状态；另存浅色和深色首屏截图，无控制台错误或失败请求。
- 该修订只影响独立原型与文档，没有改动现有网站或生成 APK。

## FrankPitwall 品牌标识

- 根据用户指定，将顶栏原有字样改为 FrankPitwall，并加入独立绘制的 FP 图形。
- 导出浅色/深色横向字标及独立图形 SVG；字形均为路径，没有运行时字体依赖。另导出透明背景 PNG。
- 浏览器检查增加品牌可访问名称、SVG 实际加载、浅色/深色版本互斥显示的断言；完整原型检查通过，六档视口无横向溢出。
- 人工检查 `frankpitwall-header-light.png`、`frankpitwall-header-dark.png` 和放大预览：品牌拼写正确，小尺寸可辨，没有额外背景框。
- 截图位于 `artifacts/native-android/design/`；品牌源文件与导出文件位于 `docs/design/native-app/brand/`。
- 联动修订：用户希望 F/P 结合更紧密。图形已从并排字母改为共享竖笔及横向笔画的一体化轮廓，以匹配的斜切连接红色 F 和 P 的闭合环；字标与头部占用尺寸保持。
- 已重新导出四个 SVG 和两个透明 PNG，检查放大图形及浅色/深色顶栏的小尺寸效果；完整原型浏览器检查通过，无横向溢出、控制台错误或失败资源。
