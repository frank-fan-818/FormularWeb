## 数据与账号检查

- 核心界面不加载 React 页面。仅现有 Turnstile 验证控件使用隔离 WebView；其余为 Compose 原生页面。
- 公开新闻、DHL、历史资料及 FIA 接口桌面只读检查返回 200。
- 使用匿名公开身份检查私有分析、预测及天气接口，均返回 401，未降低服务器访问控制。
- 不执行真实登录、注册或找回密码请求，不发送测试邮件。
- 会话在 AndroidKeyStore AES-GCM 下加密，文件不参与备份；密码和私有分析不落入公开缓存。
- 旧账号完整响应在退出 / 切换后被丢弃；旧的登录请求不能在退出后恢复凭据。
- SDK 本地路径、公开构建配置、构建缓存、APK 与测试输出均被 Git 忽略。
