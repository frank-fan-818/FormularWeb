# 原生 App 界面评审原型

这是用于评审信息架构、内容排版与触屏流程的独立浏览器原型，不是 Android 交付包，也不会成为 App 的 WebView 页面。所有成绩、积分、日程和图表均为示例数据。

已确认方向：赛事 / 榜单 / 资料 / 我的；正文一层 16px 侧边留白，以平铺列表、字号和对齐组织信息，不给信息加多层卡片框。

第二版依据用户反馈恢复网站的视觉语言：现有字体、红色强调、紧凑赛事标题、轻量网格、车手头像和车队色。保留手机导航，减少装饰性大字和过多留白。

顶栏品牌由用户指定为 **FrankPitwall**，使用 FP 图形和完整字标；浅色/深色 SVG 与透明 PNG 见 [品牌资产](brand/README.md)。只替换当前原型的品牌位置，不重命名现有 Web 项目或包名。

`site-assets.css` 由 `node docs/design/native-app/prepare-assets.mjs` 从现有网站字体及头像生成；资源内联以便直接打开文件时也能预览，不依赖外部网络。字体许可见 `public/fonts/LICENSE-*.txt`，不增加第三方图片或字体来源。

直接用浏览器打开本目录 `index.html` 即可操作；原型没有接口或模块加载依赖。也可以从仓库根目录启动本地预览：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory docs/design/native-app
```

打开 `http://127.0.0.1:8766/`。此命令只服务原型目录。

验证：`node docs/design/native-app/verify.mjs`。使用本机 Chrome；截图和检查结果写到被忽略的 `artifacts/native-android/design/`。

主要流程：

- 赛事 → 查看周末 → 成绩 → 选择场次 → 车手表现 → 返回。
- 赛事 → 完整赛历 → 赛事概览。
- 比赛 → 分析 → 圈速对比 → 选择对比车手 / 圈数 / 数据视图。
- 榜单 → 车手 / 车队 → 档案 → 返回保留列表。
- 资料 → 搜索 / 分类 → 档案。
- 我的 → 主题、时区及成绩页状态预览。

边界：轮胎策略与速度对比显示明确的待细化提示；账号不模拟真实登录。此原型不发起赛事数据请求，不缓存会话，不持久化个人设置。
