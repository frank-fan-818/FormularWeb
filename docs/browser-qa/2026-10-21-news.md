## Findings / remaining limits

- Autosport 在前期 Python GET 中返回有效 RSS，但本轮 Node / Vite 请求返回 HTTP 405；因此没有启用，不通过更换身份或绕过限制强行接入。
- 本功能在打开页面或点击刷新时获取新闻，未创建定时采集任务。内存缓存可跨同一次站内导航复用，不承诺刷新浏览器后的离线历史。
- 精选列表目前由 `src/data/curatedPosts.ts` 人工维护；刷新新闻不会自动新增 Reddit 帖子。原帖被删除、改为私有或访客无法访问 Reddit 时，嵌入可能不可用；12 秒没有有效就绪消息即提示重试并保留导读和原帖入口。
- 生产 Vercel 的两条同源重写及 CDN 策略已准备，但本轮未部署，未实测其线上出口对源站的可访问性。
- 新闻使用条件仍按来源适用范围确认；本次没有取得全文、图片或翻译的发布许可，也没有发布到公网。
- Blocking: 无本地功能阻塞。线上发布前需验证部署环境的真实 RSS 可用性和适用的来源展示条件。
