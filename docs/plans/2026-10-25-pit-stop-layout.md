# 进站用时与 DHL Pit Stop Award 布局方案

状态：已完成本地实现和验证，未提交、未部署。日期：2026-10-25。

## 实施计划（2026-10-25）

1. 补服务端来源发现、官方榜单校验、分站匹配、完整分页和计时合并测试，确认测试先失败。
2. 增加同源只读 `/api/pit-stops`，动态发现 DHL 组件，服务器缓存成功结果；异常保留最近成功结果。Jolpica 基础记录与 OpenF1 静止计时分别标记来源。
3. 在 `src/types/pitStops.ts`、`src/api/pitStops.ts`、`src/hooks/usePitStops.ts` 分离契约、请求与请求生命周期。
4. 实现独立榜单页及比赛概览进站模块，更新导航、路由与中英文文案；保留精简布局。
5. 运行来源测试、相关单测、类型检查、构建、编码检查和浏览器 QA，记录截图与实际限制。

本批仅本地实现与验证；提交、推送和生产发布等待用户的明确指令。按 `feat:` 范围记录，提交前按 version-manager 准备 minor 版本。

用户需求：在原有 pit stop time 调研基础上确定页面布局，同时包含 DHL Pit Stop Award 排行榜。

## 页面组织

产品方向：面向查询比赛进站表现的 F1 用户，主任务是比较实际计时与官方 Award 积分。采用高密度表格；桌面直接比较多列，移动端优先车手和用时，辅助字段展开查看。沿用项目设计 token、红色选中态、字体与明暗主题；不新增摘要卡或常驻解释段落。

1. 比赛详情「赛事概览」：在完整场次成绩下方增加独立「进站表现」模块，游客可读，不依赖会员 FastF1 分析加载成功。
2. 独立 `/pit-stops?season=2026` 页面：导航名称「进站榜」，主标题带 DHL Fastest Pit Stop Award；默认「赛季车队积分」，可切换「单站最快进站」。
3. 比赛详情的「本站 DHL 榜单」入口链接至选定赛季和本站；榜单保留返回比赛详情的入口。分站参数使用本站赛事标识，不直接暴露或猜测 DHL 内部 event ID。

## 展示原则（按用户反馈修订）

- 不显示「已收录 N 次」或进站记录数量卡片。
- 不为填满布局增加指标卡；取消中位数、重复的领先车队、榜单范围等摘要。
- 以排行榜与进站明细为主，减少重复标题、英文眉题、副标题和解释性小字。
- 仅保留有助于使用的数据字段、筛选、页面跳转和简短来源入口。
- 来源、计时含义等必要说明按需查看；仅异常、失败或数据不完整时给出一句具体提示。
- 草图仅保留一处「演示数据」标识，正式页面不出现演示提示或实现细节。

## 赛事概览模块

- 标题直接接明细表，不增加摘要卡片；静止计时缺失时不使用维修区总用时替代。
- 表格：车手 / 车队、圈数、第几停、静止换胎、维修区总用时。
- 默认圈数顺序，支持车手 / 车队筛选和两个用时各自排序。
- 通过简短来源入口按需查看数据出处与计时说明，不堆放模块底部小字。
- 移动端紧凑双行记录，避免必须横向滚动才能看到两个用时。

## DHL 榜单页面

### 赛季车队积分

- 默认视图优先回答「哪个维修组领先」。
- 页面筛选为赛季，不受单站选择影响。
- 筛选后直接展示积分表，不重复展示榜首车队；数据截止范围并入必要的更新状态。
- 主表：排名、车队、官方积分、距榜首积分差。
- 积分列为视觉重点；可在车队名称下辅以同一尺度的细横条，避免表格和大型图表重复占位。
- 从官方表格核对名次，保留官方对相同显示用时的不同排序；未提供名次时保留并列，不能通过数组下标捏造官方名次。

### 单站最快进站

- 筛选：赛季和分站；从比赛详情进入时自动定位。
- 直接展示最快记录表，不额外重复第一名的摘要卡。
- 表格：官方名次、车手 / 车队、圈数、官方用时、官方积分、备注 / 异常标记。
- 使用「单站最快进站」标签与「进站明细」入口区分榜单和全量记录，不附常驻解释段落。
- 同一车队多条进站保留，不按车队去重，不自行重算积分。
- 移动端保留名次、车手 / 车队和用时，展开后显示圈数、积分及备注。

## 数据边界与状态

- 延续 2026-10-21 的来源实测：Jolpica / F1DB 提供维修区总用时，OpenF1 补静止用时，DHL 官方榜单单独存储。
- DHL 公布的积分直接保存，不用通用比赛计分函数推导。
- 发现官网实际组件地址后校验赛季与分站，不能写死 CMS ID，也不能将 event ID 当作本站轮次。
- 榜单快照携带来源 URL、抓取时间、截至分站与解析版本。
- 仅在对应赛季成功核对数据后开放该赛季选项；过去验证过若干样本不等于所有历史赛事已可用。
- 加载：局部骨架；未发布：官方排名待更新；失败：局部重试；缓存：保留最近成功数据并显示截至时间。
- 不能把无数据写成零积分、零次进站，不能把 OpenF1 排序静默替换成 DHL 官方排名。
- 来源技术可读与使用条件分别核实，沿用原调研的发布前置条件。

## 本轮交付范围

- 已实现 `/pit-stops`、导航、赛季 / 分站切换及比赛概览进站模块；草图演示数据未进入网站代码。
- 同源服务端适配器动态发现 DHL 组件，核对官方 HTML 中的名次；只返回结构化数据，不执行上游 HTML。
- Jolpica 读取完整分页，OpenF1 通过年份、比赛日期和地点匹配会话，再以车号与圈数唯一匹配静止计时；歧义或缺失保留空值。
- 当前使用服务端进程成功缓存、CDN 缓存和页面会话内缓存；服务端进程重启后的失败恢复依赖上游或已有 CDN 缓存。本轮未建设数据库持久快照或定时采集任务。
- 基础明细当前从 2011 年起查询；更早历史的 F1DB 适配器未接入。DHL 目录发现 2018—2026 年，仍按具体来源返回情况展示，不承诺每站均有数据。
- 界面无数据时显示空状态；静止计时缺失显示 —。没有虚构用时、名次或积分。
- 版本未变更；本地源代码、测试、字体子集与说明文档均属于本批。提交前再依 version-manager 准备 `feat:` 的 minor 版本。
