# FrankPitwall 原生功能补齐

界面沿用已确认的 FP 联动标志、网站字体与红色强调、无卡片嵌套的列表布局。
Android 使用 Compose；浏览网站页面不能代替原生功能。

本批实现顺序：

1. 比赛：练习赛与冲刺排位、官方成绩、场次切换。
2. 资料：车手/车队生涯、赛季历史、分站成绩，赛道往届赛事。
3. 内容：Motorsport/FIA/Reddit 新闻，DHL 进站榜与实际进站数据，FIA 升级。
4. 账号：现有 Supabase 邮箱登录/注册/重置，保留 Turnstile，安全保存会话。
5. 分析：会员比赛分析、圈速/位置对比、轮胎、天气、赛控、遥测、预测。
6. 验证：映射和并发测试、身份切换隔离、Gradle 测试/Lint/APK。

公开数据使用有界磁盘缓存；会员数据仅存于当前用户的内存页面状态，退出即清空。
所有请求按比赛、赛季、场次和用户隔离。没有发布的数据不生成演示值。
新闻原文、验证邮件、密码重置允许打开系统浏览器；核心界面保持原生。
Turnstile 必须保留时，仅验证控件使用隔离 WebView，账号字段及分析页面使用 Compose。

原生版本按 feat 准备为 0.2.0。Web 版本不变。本批只做本地编辑与验证，不提交或部署。
没有连接设备时，必须如实列明安装、触控、验证码、真实账号及系统恢复仍需实机验证。
