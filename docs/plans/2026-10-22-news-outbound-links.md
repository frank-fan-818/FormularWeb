# 新闻与精选改为直接原文链接

用户决定沿用链接聚合，删除导读，点击直接跳转。该决定取代先前的站内导读 / Reddit 嵌入方案。

- 主要任务：从新闻或精选列表打开来源内容；保留分类、搜索、来源、日期和用户此前要求的精简布局。
- 标题与操作链接直接使用已校验的媒体原文 / 精选原帖地址，在新标签页打开，保留列表位置。
- 删除简介展示、简介字段与解析、站内阅读路由、详情页和 Reddit 嵌入；清理路由预加载、闲置样式 / 文案与额外 frame-src。
- 桌面和手机使用现有 tokens 和列表，不增加新视觉组件。验证加载、空结果、来源失败及缓存行为。
- 更新现有单元与浏览器检查：实际点击打开精确的外站地址，没有中间页面；不预加载外站，不执行 feed 正文或请求其中图片。
- 同一未提交新闻功能继续使用准备中的 1.2.0，未提交、部署或申请任何授权。
