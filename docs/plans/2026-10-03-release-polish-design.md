# 发布候选版本与视觉收口

## 产品方向

- 受众：查看赛周、积分与比赛分析的 F1 用户。
- 首页主任务：五秒内找到当前赛事、领先者与下一场日程；移动端优先保证信息可读和主操作可达。
- 保留赛事指挥台视觉：深色赛事面板、红色主操作、紧凑的时间与排名；通过状态反馈建立特色。
- 方案取舍：选择现有设计系统的精修；整体重做会增加发布风险；增加大型 3D 或滚动特效会增加数据产品的阅读与加载成本。

## 本轮实施

1. 修复主题切换后深色面板白字落在浅底的问题，包括首页、跨页赛周提示、积分榜选中标签。
2. 首页游客权限提示使用紧凑布局，保持登录边界与返回地址；延后加载预测摘要，降低首页关键 JavaScript 体积。
3. 增加键盘跳转正文入口，强化首页焦点与触控目标；长标题允许合理换行。
4. 更新当前发布证据，分别列出本地通过、工具阻断与待核实的生产事项。
5. 修复空积分榜高度、赛周日期与账号首帧可见性；精简登录基础控件和启动模块，验证延迟 SDK、回调参数和会员访问边界。
6. 补真实 hook 生命周期回归，修复跨赛季缓存串用与密码恢复令牌刷新问题。
7. 图表提供分页数据表，支持键盘访问；轴标签跟随主题，保留车手与赛道状态语义色。
8. 自托管授权字体并按入口字形拆包，增加哈希、声明文件和中文覆盖门禁；复测冷启动性能。
9. 增加发布身份、GET-only 线上探针、生产健康工作流和回滚手册；补桌面 Firefox 与移动 WebKit 核心流程。

## 验收

- 1440×900、768×1024、375×812；亮色、暗色与减少动效。
- 首页主标题与深色背景对比度至少 4.5:1；游客提示不抢占主信息层级；不发起受保护数据请求。
- 键盘可跳过重复导航到正文；无页面水平溢出。
- 全量单测、严格 lint、生产构建、原有性能预算、浏览器 QA；不降低门槛以通过检查。
- 截图保存于 artifacts/browser-qa/screenshots/；当前证据记录于 docs/release-readiness-report.md。

## 发布判断

本轮完成本地候选版本准备，不把生产 RLS、认证回调、数据完整性、发布与回滚的历史验证冒充当前验证。奖项标准作为设计审查参考，获奖与“永远没有可优化点”不作为未经外部验证的承诺。
