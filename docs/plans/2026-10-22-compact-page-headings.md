# 全站标题区精简

用户要求移除各页面标题上方的编号 / 英文装饰标签，并缩小标题框。主要任务是让访客更快看到正文及操作；复用原有 design tokens，不改数据与图表逻辑。

- 统一删除 ProductMasthead 与 ProductSectionHeader 的 index / eyebrow API 及调用属性，不用 CSS 隐藏残留。
- 车手 / 车队档案和账号卡片的同类装饰 eyebrow 一并移除；国籍、车队、赛季、比赛轮次等有用身份信息保留。
- 赛事子页 RacePageIntro 和隐私页同类英文装饰标签一并移除。
- 公共标题区缩小标题字号、上下留白、模块间距，并同步统计栏边距；新闻与车队列表取消大字号覆盖。
- 车手 / 车队详情英雄区降低桌面最小高度和 padding；移动端图片与文字仍自然分行。
- 验证新闻、赛季积分、赛历、车手 / 车队列表和详情、赛道及设置；桌面 1440×900、手机 375×812、平板 768×1024，无溢出和控件覆盖，标题与统计仍可读。
- 本轮为未发布版本中的视觉调整，继续准备中的 1.2.0，不提交或部署。
