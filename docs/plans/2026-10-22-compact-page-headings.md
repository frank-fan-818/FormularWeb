# 全站标题区精简

用户要求移除各页面标题上方的编号 / 英文装饰标签，并缩小标题框。主要任务是让访客更快看到正文及操作；复用原有 design tokens，不改数据与图表逻辑。

- 统一删除 ProductMasthead 与 ProductSectionHeader 的 index / eyebrow API 及调用属性，不用 CSS 隐藏残留。
- 车手 / 车队档案和账号卡片的同类装饰 eyebrow 一并移除；国籍、车队、赛季、比赛轮次等有用身份信息保留。
- 赛事子页 RacePageIntro 和隐私页同类英文装饰标签一并移除。
- 公共标题区缩小标题字号、上下留白、模块间距，并同步统计栏边距；新闻与车队列表取消大字号覆盖。
- 车手 / 车队详情英雄区降低桌面最小高度和 padding；移动端图片与文字仍自然分行。
- 验证新闻、赛季积分、赛历、车手 / 车队列表和详情、赛道及设置；桌面 1440×900、手机 375×812、平板 768×1024，无溢出和控件覆盖，标题与统计仍可读。
- 本轮为未发布版本中的视觉调整，继续准备中的 1.2.0，不提交或部署。

## 追加：单行标题与赛道统计精简

- 移除赛道、车手、车队、赛历、积分榜标题中的手动换行。公共标题使用单行排版，缩小字号、上下 padding 和相邻间距；过长的赛道名称在窄屏显示省略号，保留完整文本与原生悬停提示。
- 标题区不再为未使用的侧栏预留固定宽度。赛道页仅保留“本季赛道”数量，删除工程数据覆盖量、冲刺周末和附属说明；桌面数量与标题并排，手机数量为紧凑的一行。
- 保留其他页面的数据统计和现有数据加载流程。更新已有页头回归检查单行标题、静态标题不截断、赛道单项统计及浅深色主题；继续按 `style:` 处理，版本不变。

## 追加：独立标题区

- 首页赛事标题、赛事详情标题、赛事子页标题、车手与车队档案、历史档案、账号表单标题和隐私页标题也采用紧凑字号与单行排版。
- 车手名与姓改为同一行；车手和车队档案保留车队色、照片、赛车图片及身份信息，桌面最小高度缩至 220px，手机车手照片区缩至 180px，避免标题变小后仍留下高大的外框。
- 长名称在窄屏允许省略显示，但完整文本和悬停提示保留。既有档案回归改为检查同一行的姓名及完整 title 文本，继续检查图片、身份信息和正文无重叠。
