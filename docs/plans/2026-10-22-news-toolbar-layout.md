# 新闻筛选区排版

用户希望优化新闻分类及搜索区域。采用局部排版调整，保持筛选、数据更新和原帖跳转行为。

- 分类按钮收进统一分段控件，用现有设计 tokens 表达选中 / 悬停状态，保留 44px 触控高度。
- 足够宽的内容区域（760px 起）分类在左、搜索与来源筛选在右；按内容容器宽度切换，兼容侧栏与窗口尺寸变化。
- 窄屏分类独占第一行，搜索独占下一行（有来源筛选时并排）；减少控件间距和重复可见标签，保留完整可访问名称。
- 搜索框增加搜索图标；使用更轻的分隔线，降低视觉重量。
- 验证中英文、浅 / 深色、375 / 768 / 1440 宽度，筛选、输入框、刷新及分页继续可用；截取分类区证据。
- 本轮继续当前未发布的 1.2.0，不提交或部署。
