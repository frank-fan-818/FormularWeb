## Version decision

The change includes a user-facing authentication message fix (`fix:`) and explicit
first-stable release preparation requested by the maintainer. The source target
is therefore `1.0.0`, rather than applying another automatic 0.x patch bump.
It remains an unreleased candidate until the remaining gates pass.

## Release rule

Publish only after all P0 gates have current evidence. A passing fixture test is
not evidence of live database permissions or email delivery. Record unavailable
checks as pending, not passed. P1/P2 improvements remain outside this release.
