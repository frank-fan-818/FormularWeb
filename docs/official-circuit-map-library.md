# 官方赛道图库覆盖清单

核查日期：2026-10-23 至 2026-10-24。范围为仓库 F1DB 的 78 条赛道身份；现有 32 条，本次新增 18 条，共 50 条已入库，28 条保留缺口记录。这里的“已入库”指官方来源及可读标注已核验，不表示已经提交或部署。

标准：优先 F1，再选 FIA、赛道运营方或赛事官方技术资料；核对真实赛道身份、资料年份、弯道/起终点/分段等标注。排除照片、无标注轮廓和第三方重绘。PDF 保留整页标注，记录原件 SHA-256、页码及渲染方式。

查看器在明暗主题均为白底。官方图本身的颜色、Logo、标注和历史原件纸色保持原样。Porto 是 1958 年官方档案扫描；不将其纸色处理成新的白底重绘。

资料年份不等于该赛道的 F1 比赛年份。Bugatti、Kyalami、Estoril、Jerez、Sebring、Watkins Glen、Fuji、Dijon、Anderstorp 等条目记录其实际布局版本，不能用于推断其他年代的历史走线；详细限制见下表及源清单。赛道档案的历史统计卡片没有在本次任务中重算。

## 维护与验证

- 图片：public/images/circuits/detailed/。运行时来源清单：src/data/circuit-detailed-maps.json。50 张图合计 7,509,781 字节，单张最大 674,448 字节。仅在赛道相关页面请求，列表图片延迟加载。
- `npm run circuits:check`：校验全部图片的真实编码、尺寸、字节数和 SHA-256，检查来源域名、布局说明、目录覆盖及重复项。
- `npm run circuits:import -- path/to/reviewed-import.json`：离线导入人工核验后的条目；`maps` 数组中每项为清单元数据，另带指向本地图片的 `file`。PDF 条目还需原件哈希/大小、renderPage、renderLongestEdge 和 renderer。不要把未审查的下载文件直接作为正式条目。
- 所有待导入记录在写入前校验；未知赛道、路径越界、非批准来源、格式/尺寸/哈希不符及重复 ID 会拒绝。已有条目可重复导入，但不同内容的覆盖会拒绝，需先核对并显式维护清单。
- PDF 更新：重新取得官方原件，核对页码和布局，用 Poppler 渲染选定页面；不裁掉图例、不补画走线。输出记录原件校验和、页码、渲染最长边和压缩方式。图像压缩后保留原始尺寸并复查标注。
- 2026 F1 页面中的 `/bahrain` 当前提供 Sepang 图片：清单按图片实际赛道身份保存为 sepang，Sakhir 继续使用已验证的 2025 官方图；两者有独立 ID 和回归测试。

发布版本与部署状态以 GitHub Release 和生产站点的 release.json 为准；入库日期不等于发布时间。1.3.0 的发布范围与限制见 docs/release-notes-v1.3.0.md。
