## Behavior

- Supply basic metadata for all 78 repository circuits, normalize calendar/history aliases, and preserve known data when remote fields are absent or contain placeholders.
- Race intelligence shares circuit direction and corner counts with the circuit catalogue, retaining available left/right corner counts alongside the total. Missing FastF1 weather can use same-race OpenF1 measured observations through an authenticated, non-cacheable summary endpoint.
- DHL event responses no longer fail merely because `event_id` is absent; venue/date identity and official table ranks/timing precision remain checked.
- Standings, season-fastest stops and event leaderboards check for changes every five minutes while visible and online, and refresh on focus/reconnection. Failures retain marked stale data and retry automatically. Upstream/instance caches are one minute; browser/CDN caches are disabled for pit responses.
- Optional weather/pit clients load on demand. A duplicate account-card preload was removed without changing login first-paint behavior or raising performance budgets.
