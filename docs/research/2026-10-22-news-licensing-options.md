# 赛车新闻产品的内容模式与授权申请

核查日期：2026-10-22（Asia/Shanghai）。本轮只研究公开资料、准备询价文字，没有联系媒体、申请账号、同意合同、支付费用或改变网站功能。

## 结论

类似产品主要采用：标题与链接聚合、独立编辑的资讯汇总、经商业合作分发的报道。不能仅凭一个应用展示很多新闻，就推定它取得了所有内容的再分发权。对于本站希望的中文站内阅读，优先询问 Planet Sport 的 F1 供稿方案、RaceFans 的文章许可，再向 Motorsport Network 询问现有来源的合作条件。

以下优先顺序是根据公开服务与本站需求的匹配程度作出的建议，不是费用、获批概率或回复时长排名。

## 可联系的许可渠道

### 1. Planet Sport / PlanetF1

- 服务证据：[Syndication Services](https://www.planetsport.com/syndication-services)。
- 现行 [PlanetF1 联系页](https://www.planetf1.com/contact-us)列出一般商业联系 `info@planetsport.com`；编辑邮箱 `planetf1editor@planetsport.com` 可以帮助转交，但不能当作已确认的授权审批邮箱。
- 建议询问：适用于中文车迷网站的 F1 纯文字授权、可选全文翻译、低篇数试用，以及专用 feed 的报价。
- 未确认：是否接受本站体量、是否含中文权利、第三方稿件及摄影是否可转授。没有找到固定公开价格。

### 2. RaceFans

- [官方 FAQ](https://www.racefans.net/f1-information/f1-faq/f1-fanatic-faq/)说明可以联系购买文章，不允许以任何语言免费重发；大部分配图来自其他权利人，RaceFans 无法授权他人再用。
- 联系入口：[官方联系表单](https://www.racefans.net/contact/contact-racefans/)。
- 建议先问少量指定文章的中文网络发布许可，图片另列，不假设“购买文章”必然包含翻译或永久存档。
- 本轮直接读取 FAQ / 表单返回 429；上述政策由官方页面的搜索索引核对，未提交或验证表单交付。没有查到文章统一价目表。

### 3. Motorsport Network / Motorsport.com / Autosport

- [集团联系页](https://www.motorsportnetwork.com/company/contacts)提供 Partnerships 类别及 `info@motorsportnetwork.com`。这是一般咨询入口，请其转 content licensing / syndication 负责人。
- Yahoo 官方合作公告可证明该集团存在内容合作模式，不证明有面向所有开发者的标准自助许可。
- 本站已有 Motorsport RSS 技术接入，因此值得申请明确的中文标题 / 短简介 / 全文三种范围报价；不能将技术接通当作许可获批。
- 未找到适合本站的公开固定报价、明确的自助翻译授权或服务承诺。

### 4. Guardian（F1 补充报道）

- [Open Platform 申请页](https://open-platform.theguardian.com/access/)区分非商业 Developer 和 Commercial：开发层有文章正文、每日 500 次请求上限；商业价格依用途确定。
- [许可 FAQ](https://licensing.theguardian.com/frequently-asked-questions)列出单篇购买、按月订阅和有限非商业使用；单篇应通过文章的 “Reuse this content” 入口申请。它也说明部分第三方材料无法由 Guardian 转授权。
- API 咨询可用[平台首页](https://open-platform.theguardian.com/)公开的 `openplatform@theguardian.com`；单篇购买优先遵循 FAQ 指定的申请表。
- 默认 API 许可不含自行翻译权，中文发布需另谈。[API 条款](https://www.theguardian.com/open-platform/terms-and-conditions)。

### 5. F1 官网 / FIA 公告

F1 [Legal Notices](https://www.formula1.com/en/information/legal-notices.7egvZU48hzrypubGBNcQKt)对 RSS 聚合、修改和跳转另有限制，不作为默认全文来源。公告和车队新闻稿可以作为核实事实的入口；媒体资料可下载、持有媒体账号或获准采访，不应推定拥有所有正文 / 图片的再发布权。本站当前 FIA 技术源的使用范围仍未获得书面确认。

## 询价时提交的项目说明

先准备一页材料，不必先实现全文抓取器：

1. 网站名称、经营主体或个人身份、真实域名、新闻页截图；说明新闻模块正在本地验证。
2. 服务人群与语言：中文 F1 车迷；网站全球可访问时，要确认地区许可是否覆盖这种访问范围。
3. 真实月访问量、预计发布篇数；未知数字留待补充，不捏造。
4. 现有与计划中的广告、赞助、会员、收费安排；不能把免费阅读自动写成非商业。
5. 可接受的署名、原文链接及发布时间标注方式。
6. 分别询问三档：标题与短导读、完整中文译文、文字加指定图片。纯文字通常便于界定范围，但不预设一定更便宜。

## 要求书面确认的范围

- **内容与权利人**：哪些栏目、具体稿件、通讯社稿、作者稿可授权；对方是否有权授予所需用途。
- **使用方式**：站内全文展示、标题改写、翻译、摘要分别是否允许；使用 AI 辅助翻译 / 摘要或外部服务处理须另问，不默认包括。
- **媒体范围**：响应式网页、未来 App、公众号及通知推送是否分别计费。
- **语言与地区**：简体中文；授权地区及全球网站访问的处理方式。
- **图片 / 视频**：是否包含，是否可裁剪、做缩略图、缓存；排除不能转授的摄影及赛事影像。
- **商业与数量**：广告、赞助、会员用途；按篇、月费、最低保底、超额价格、试用是否可谈。
- **技术与存档**：API / feed、调用频率、缓存时间、纠错同步、下架要求，合同到期后旧文章是否保留。
- **期限与证据**：明确域名 / 主体、起止日期、署名模板和批准方式；保存合同、邮件、发票与授权附件。没有回复不代表同意。

“免费试用一个月、限定每月约 10 篇、先不含图片”可以作为谈判提案，不是已存在的官方优惠或获批承诺。
